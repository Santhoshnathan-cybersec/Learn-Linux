LINUX COMMANDS CHEAT SHEET BY @zanthoshh

This guide is for beginners. It groups commands by topic, explains them in plain language, and shows small examples you can try.

How to read the examples:
- `zanthoshh@whitehat:~$` is just the terminal prompt from my computer.
- The part after `$` is the command you type.
- The next lines are the result you see after running it.
- Linux commands are case-sensitive, so `File.txt` and `file.txt` are different.

Quick safety rules:
- Be careful with `rm`, `sudo`, and `chmod`.
- Always check the path before deleting anything.
- If a command looks confusing, read `man <command>` first.

================================================================================
1. WHERE AM I? BASIC SYSTEM INFO
================================================================================

`pwd` - print the current directory.

```text
zanthoshh@whitehat:~$ pwd
/home/zanthoshh
```

`uname -a` - show kernel, machine, and system details.

```text
zanthoshh@whitehat:~$ uname -a
Linux whitehat 7.0.0-28-generic #28~24.04.1-Ubuntu SMP PREEMPT_DYNAMIC ...
```

`whoami` - show the current username.

```text
zanthoshh@whitehat:~$ whoami
zanthoshh
```

`history` - show previous commands.

```text
zanthoshh@whitehat:~$ history
```

`clear` or `Ctrl + L` - clear the terminal screen.

`man <command>` - open the manual page for a command.

```text
man ls
```

`which <command>` - show where a command is installed.

```text
which python3
```

================================================================================
2. NAVIGATING FILES AND FOLDERS
================================================================================

`ls` - list files and folders.

```text
zanthoshh@whitehat:~/linuxdataengsample$ ls
hello.txt  test.txt
```

Useful `ls` options:
- `ls -l` - long format with permissions, owner, size, and date.
- `ls -a` - show hidden files.
- `ls -lh` - human-readable file sizes.
- `ls -ltr` - list by time, oldest first.
- `ls -lstr` - useful when you want size plus time ordering.

`cd` - change directory.

```text
zanthoshh@whitehat:~/linuxdataengsample$ cd folder1
zanthoshh@whitehat:~/linuxdataengsample/folder1$
```

`cd ..` - go up one folder.

`cd ../../..` - go up multiple levels.

`cd ~` or `cd ~/` - go to your home directory.

`cd -` - jump back to the previous directory.

`mkdir` - create folders.

```text
mkdir folder1
mkdir -p 1dir/2dir/3dir
```

`touch` - create an empty file.

```text
touch notes.txt
```

Tab completion:
- Press `Tab` to auto-complete file and folder names.
- If many names start the same way, type a few more letters and press `Tab` again.

Hidden files:
- A file or folder that starts with `.` is hidden.
- Example: `.env`, `.gitignore`, `.hidden-notes.txt`.

================================================================================
3. VIEWING AND EDITING FILES
================================================================================

`cat` - print file content quickly.

```text
cat test1.txt
```

`less` - view large files one screen at a time.

```text
less /var/log/syslog
```

`head` - show the first lines of a file.

```text
head number.txt
head -n 5 number.txt
```

`tail` - show the last lines of a file.

```text
tail logfile.txt
tail -f logfile.txt
```

`tail -f` is especially useful for live logs because it keeps following new lines.

`nano` - simple text editor.

```text
nano hello.txt
```

Useful nano keys:
- `Ctrl + O` - save the file.
- `Ctrl + X` - exit.

`vi` or `vim` - powerful text editor.

Basic vi flow:
- Type `vi filename`
- Press `i` to enter insert mode
- Press `Esc` to leave insert mode
- Type `:w` to save
- Type `:q` to quit
- Type `:wq` to save and quit

================================================================================
4. COPYING, MOVING, RENAMING, AND DELETING
================================================================================

`cp` - copy files or folders.

```text
cp test1.txt test2.txt
cp -r folder1 folder1-backup
```

`mv` - move a file or rename it.

```text
mv test1.txt rename.txt
mv report.txt backup/report.txt
```

`rm` - remove files.

```text
rm test.txt
rm *.txt
```

`rm -rf` deletes folders forcefully. Use it carefully.

```text
rm -rf old-folder
```

`rmdir` - remove an empty directory.

```text
rmdir empty-folder
```

================================================================================
5. TEXT, OUTPUT, AND REDIRECTION
================================================================================

`echo` - print text to the terminal.

```text
echo "hello from Xytron@zanthoshh"
```

Redirection basics:
- `>` writes output to a file and overwrites the file.
- `>>` appends output to a file.

```text
echo "first line" > notes.txt
echo "second line" >> notes.txt
```

`>` means replace the file content.
`>>` means keep the old content and add new content at the end.

`cat file1 >> file2` - append one file into another.

```text
cat test2.txt >> test3.txt
```

`tee` - send output to both the screen and a file.

```text
echo "hello" | tee output.txt
```

`wc` - count lines, words, and characters.

```text
wc wordcount.txt
wc -l wordcount.txt
wc -w wordcount.txt
wc -c wordcount.txt
```

`sort` - sort text.

```text
sort names.txt
sort -r names.txt
sort -n numbers.txt
sort -n -r numbers.txt
```

`uniq` - remove repeated adjacent lines.

```text
sort names.txt | uniq
sort names.txt | uniq -c
```

`cut` - extract columns or fields.

```text
cut -d ':' -f 1 /etc/passwd
```

`tr` - transform characters.

```text
echo "hello" | tr 'a-z' 'A-Z'
```

`sed` - stream editor for quick text replacement.

```text
sed 's/old/new/g' file.txt
```

`awk` - powerful text field processor.

```text
awk '{print $1, $3}' data.txt
```

================================================================================
6. SEARCHING FOR TEXT AND FILES
================================================================================

`grep` - search for text inside files.

```text
grep XYTRON log2.txt
grep -i xytron log2.txt
grep -v XYTRON log2.txt
```

Useful `grep` options:
- `-i` - ignore case.
- `-v` - show lines that do not match.
- `-r` - search recursively inside folders.
- `-n` - show line numbers.
- `-w` - match whole words only.

Examples with folders:

```text
grep -r "xytron" ~/linuxdataengsample/
grep -n "error" logfile.txt
grep -w "root" /etc/passwd
```

`find` - search for files and folders.

```text
find . -name list.txt
find . -type f -size +20M
find . -empty
find . -mtime 1
```

Useful `find` patterns:
- `-name` - search by name.
- `-type f` - only files.
- `-type d` - only folders.
- `-size +20M` - bigger than 20 MB.
- `-empty` - empty files or folders.
- `-mtime 1` - modified around 1 day ago.

`xargs` - pass results of one command into another.

```text
find . -name "*.txt" | xargs grep -n "linux"
```

================================================================================
7. PROCESS MANAGEMENT
================================================================================

`top` - live view of CPU, memory, and running processes.

`htop` - friendlier version of top, if installed.

`ps aux` - list running processes.

```text
ps aux
ps aux | grep simple.py
```

What the letters mean:
- `a` - show processes from all users.
- `u` - include the owner and extra details.
- `x` - show processes not attached to your terminal.

`grep` is often used with `ps` to find one process quickly.

`kill` - stop a process by PID.

```text
kill 1234
kill -9 1234
```

Use `kill -9` only when a normal kill does not work.

`jobs` - show background jobs in the current terminal.

`fg` - bring a stopped/background job back to the foreground.

`bg` - continue a stopped job in the background.

================================================================================
8. DISK AND MEMORY
================================================================================

`df -h` - show disk usage in human-readable form.

```text
df -h
```

`du -sh <file-or-folder>` - show size of one item.

```text
du -sh simple.py
du -sh Downloads/
```

`free -m` - show memory usage in megabytes.

```text
free -m
```

`free -g` - show memory usage in gigabytes.

If the system feels slow, check both `free` and `top` first before doing anything risky.

================================================================================
9. ARCHIVES AND COMPRESSION
================================================================================

`zip` - create a zip archive.

```text
zip -r hardlinkr.zip hardlink/
```

`unzip` - extract a zip archive.

```text
unzip hardlinkr.zip
```

`tar` - create or extract tar archives.

Create a tar.gz archive:

```text
tar -czvf folder1.tar.gz folder1/
```

Extract a tar.gz archive:

```text
tar -xzvf folder1.tar.gz
```

Flag meanings:
- `c` - create
- `x` - extract
- `z` - use gzip compression
- `v` - show verbose output
- `f` - use a file name

================================================================================
10. PERMISSIONS AND OWNERSHIP
================================================================================

`chmod` - change file permissions.

Permissions basics:
- `r` = read
- `w` = write
- `x` = execute

Numeric mode examples:
- `7` = read + write + execute
- `6` = read + write
- `5` = read + execute
- `0` = no permission

```text
chmod 777 changingpermissions.txt
chmod -R 777 foldername/
```

Use `777` only for learning or temporary testing. In real projects, it is usually too open.

`chown` - change owner of a file or folder.

```text
sudo chown zanthoshh:zanthoshh file.txt
```

`sudo` - run a command with administrator privileges.

```text
sudo apt install zip
sudo su
exit
```

`sudo su` switches to the root user. `exit` gets you back to your normal user.

================================================================================
11. LINKING FILES
================================================================================

`ln` - create links.

Hard link example:

```text
ln original.txt hardlink.txt
```

Symbolic link example:

```text
ln -s original.txt shortcut.txt
```

Hard links point to the same file data. Symbolic links point to a path.

12. POWERFUL EVERYDAY COMBINATIONS
================================================================================

Pipeline example:


Another useful pipeline:


Count lines in a folder of text files:
